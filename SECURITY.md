# Security

This development project has no published releases or established private security contact yet. Before public distribution, maintainers must establish a private reporting channel and document supported versions.

Avoid including credentials, private source, or sensitive logs in public reports. Once a hosting repository and private advisory channel exist, use that channel for exploitable vulnerabilities.

Security-sensitive invariants include strict settings validation, escaped labels, safe source-expression selection, structural ownership checks, synchronized document versions, and LSP-only stdout. Changes to these areas should include protocol regression coverage.
